ПакетыPackages

Приложения для LisunOS. Ставятся по имени — система сама находит пакет в catalog.json и качает его отсюда. Applications for LisunOS. Install them by name — the system finds the package in catalog.json and downloads it from here. 

apt install sshapp                 по имени из каталогаby name from the catalog
apt install <ссылкаlink>.lnsh            или прямой ссылкой на файлor with a direct link to the file
store                            тот же список внутри системыthe same list inside the system
types                            какие бывают типы пакетовwhat package types exist

Свой пакетYour own package

Пакет .lnsh — обычный ZIP: манифест, сценарий установки, описание формы и логика. A .lnsh package is a plain ZIP: a manifest, an install script, a form description and the logic. 

meta.json          имя, тип, версия, запрашиваемые праваname, type, version, requested rights
main.lsi           сценарий установкиinstall script
<имяname>.service      приложение и его форма, блоки daemonthe application and its form, daemon blocks
assets/Form1.designer.cs   разметка окнаthe window layout
assets/Form1.cs            связка с логикой в ядреthe bridge to the logic in the core

Готовый скелет и полная спецификация — в описании шаблона или в папке template. A ready skeleton and the full specification live in the template description or in the template folder.
