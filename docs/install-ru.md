# Установка утилит LisunOS

Документ описывает, как ставить и настраивать встроенные утилиты
LisunOS 1.5.0 «Aurora». Все команды вводятся в терминале системы —
строка `LisunOS:\>` на вкладке «Терминал».

## Первый запуск

Распакуйте архив и запустите `LisunOS.exe`. Требуется **.NET Framework 4.8**
(входит в Windows 10 версии 1903 и новее). Установка не нужна — рядом с `.exe`
при первом старте разворачивается рабочая среда:

```text
[папка с .exe]
└── files/os/
    ├── root/regedit/   CONFIG и DATA — реестр системы
    ├── root/www/       корень сайта
    ├── sys/services/   установленные приложения
    ├── sys/php/        свой PHP, если он скачан
    └── temp/           временные файлы
```

Полезное сразу после запуска:

```text
help              список всех команд
sysinfo           сведения о системе
lang en           переключить язык интерфейса на английский
layout            раскладка клавиатуры
```

## Пакетный менеджер apt

```text
apt list                     что установлено
apt update <имя>             сведения о пакете из meta.json
apt install <ссылка.lnsh>    установить пакет по ссылке
apt install <имя>            скачать по имени из каталога на сайте
types                        типы пакетов: app, service, daemon, library,
                             theme, locale, module, hall
apt remove <имя>             удалить пакет
apt info <имя>               подробности и выданные права
sudo apt install <...>       то же самое от суперпользователя
```

Пакет `.lnsh` — обычный ZIP с `meta.json`, `main.lsi`, файлом службы и папкой
`assets`. После установки файлы пакета шифруются (AES-256-CBC), поэтому
исходники не остаются на диске открытыми.

## Приложения: Проводник и Сервер

Оба архива лежат в релизе, в папке `packages`, и на GitHub в папке `apps`.

```text
apt install explorerapp
apt install webserverv2
apt install sshapp
apt install superuserapp
apt install logsapp
```

Имя ищется в каталоге на сайте, и пакет скачивается оттуда. Если сети нет,
ставится встроенная копия — система скажет об этом отдельной строкой.
Ссылка на файл по-прежнему работает:

```text
apt install https://github.com/Winnigames2024-Original/LisunOS/raw/main/apps/explorerApp.lnsh
```

При установке система спросит права — их запрашивает само приложение.

| Пакет | Версия | Запуск | Что делает |
|-------|--------|--------|------------|
| ExplorerApp | 1.2.0 | `explorer`, `files` | проводник виртуальной файловой системы |
| WebServerV2 | 2.1.0 | `webserverv2`, `httpd`, `server`, `www` | панель HTTP-сервера |
| SshApp | 1.0.0 | `ssh-app` | вход в оболочку с телефона или другого ПК |
| SuperUserApp | 1.0.0 | `superuser`, `su-app` | выдача права superuser пакетам |
| LogsApp | 1.0.0 | `logs` | журнал ядра с поиском и выгрузкой |
| CalcApp | 1.0.0 | `calc`, `calculator` | калькулятор с историей |
| SettingsApp | 1.0.0 | `settings`, `options` | параметры системы |
| StoreApp | 1.0.0 | `store`, `apps-store` | каталог приложений |
| TemplateApp | 1.1.0 | `template`, `tpl`, `demo` | шаблон для своего приложения |

### Что нового в Проводнике

Кнопки «вперёд», «домой» и «обновить»; путь в адресной строке можно
править и нажать Enter; поле фильтра отбирает файлы по имени; выделять
можно несколько объектов сразу. В контекстном меню появились «Копировать»,
«Вырезать», «Вставить», «Упаковать в .zip», «Распаковать» и «Свойства»;
щелчок по заголовку столбца сортирует список, снизу видно число объектов
и их объём. Горячие клавиши: `Ctrl+C/X/V/A`, `Ctrl+L` (адрес),
`Ctrl+F` (фильтр), `F2`, `F5`, `Delete`, `Backspace`, `Alt+←`, `Alt+→`.

### Что нового в Сервере

Справа — список узлов из конфигурации: корневой и каждый блок
`server { ... }`, включая подключённые через `include`. Кнопка
«Перечитать конфиг» применяет правку `.htaccess` без остановки сервера,
а значит не рвёт открытые соединения. У журнала появились поле фильтра и
кнопка очистки, в строке статистики — сколько байт отдано клиентам.

## PHP — модуль php-frm

```text
apt install php-frm
```

PHP работает сразу: внутри LisunOS есть **свой движок** (341 функция),
внешний `php-cgi.exe` не нужен. Сборка PHP для Windows при этом
**скачивается сама**, как только появляется интернет, и подключается
без перезапуска.

```text
php-frm status                сводка: источник, автозагрузка, ход загрузки
php-frm download              скачать сборку прямо сейчас
php-frm update                перекачать заново
php-frm remove                удалить скачанный PHP, вернуться на свой движок
php-frm mirrors               список зеркал загрузки
php-frm auto off              выключить автозагрузку
php-frm use builtin           работать только на своём движке
php-frm use own               использовать скачанный PHP
php-frm use system            использовать PHP, установленный в Windows
```

Свой путь к PHP:

```text
apt install php-frm C:\php\php-cgi.exe
apt install php-frm C:\Downloads\php-8.3.zip
```

Свои адреса зеркал — в реестре:

```text
regedit -set:php_download_url -val:https://example.com/php.zip
```

## Wi-Fi

```text
wifi                          список сетей вокруг
wifi form                     окно с выбором сети и полем пароля
wifi connect "Имя сети"       открытая сеть — без пароля
wifi connect "Имя" пароль     сеть с паролем
wifi status                   адаптер, текущая сеть, состояние интернета
wifi disconnect               отключиться
wifi forget "Имя"             удалить сохранённый профиль
wifi portal                   открыть страницу входа
```

Что происходит при подключении:

* **сеть без пароля** — подключение сразу, поле пароля не нужно;
* **сеть с паролем** — создаётся профиль WPA3/WPA2/WPA, пароль нигде не остаётся;
* **сеть с авторизацией** — после подключения система видит, что интернет
  подменён страницей входа, и открывает её в браузере LisunOS.

Нужно право `network` — приложение запросит его само.

## Системный порт 8989

Прямой эфир установки PHP: видно, как система ищет сеть, качает сборку
и подключает её.

```text
system start                  открыть порт
system open                   открыть страницу в браузере
system status                 состояние порта
system stop                   закрыть порт
```

Адрес: `http://localhost:8989/php-frm.html?action=setup`

Порт системный и слушает только localhost. Он откроется лишь тогда,
когда приложению зала выдано право **`hall`**:

```text
perm grant LisunOS.lshall hall
```

Если право отозвать, порт закроется сам на следующем запросе.

## Веб-сервер и панель

```text
webserverv2                   открыть панель сервера
httpd                         то же самое
```

В панели: порт, корень сайта, автозапуск, кнопка «Управлять файлами»
для папки `www`, секретный ключ API и пароль веб-панели.

Файлы в `www`:

| Файл | Назначение |
|------|------------|
| `.htaccess` | настройка в стиле nginx: `location`, `index`, `error_page`, PHP, прокси на Node.js |
| `api.php` | приём запросов `?key=<ключ>&action=<действие>` и функция `ServerAPI()` |
| `panel.php` | веб-панель управления, вход по паролю |

Действия API: `list_files`, `read_file`, `create_file`, `edit_file`,
`delete_file`, `move_file`, `create_folder`, `delete_folder`, `status`.

Из PHP:

```php
<?php
require_once __DIR__ . '/api.php';

echo ServerAPI('ваш-ключ', 'create_file', 'notes.txt', 'Привет!');
```

Строки между `~~~NOREMOVE~` и `~NOREMOVE~~~` менять нельзя, а сам файл
нельзя удалить. Текст между `~~~CANTEDIT~` и `~CANTEDIT~~~` менять нельзя,
но файл удалить можно.

## Разрешения

```text
perm all                      все права системы с описаниями
perm list                     кому что выдано
perm app <имя>                права одного приложения
perm grant <имя> <право>      выдать
perm revoke <имя> <право>     отозвать
perm reset <имя>              сбросить все права приложения
```

| Право | Что открывает |
|-------|---------------|
| `superuser` | всё сразу |
| `read_files` | чтение файлов |
| `write_files` | создание файлов |
| `edit_files` | правка файлов |
| `manage_files` | перемещение и удаление |
| `edit_settings` | реестр и настройки |
| `network` | сеть, сокеты, сервер |
| `run_services` | запуск других служб |
| `show_dialogs` | окна сообщений |
| `autostart` | запуск вместе с системой |
| `hall` | системные порты и службы оболочки |
| `background` | работа по таймеру без окна |
| `listen` | приём входящих подключений |
| `manage_packages` | установка и удаление пакетов |
| `manage_users` | учётные записи для входа по сети |
| `appearance` | язык, раскладка и оформление |
| `clipboard` | буфер обмена Windows |
| `run_external` | запуск внешних программ Windows |
| `read_log` | чтение журнала ядра |

Отклонённое право спрашивается снова при следующей попытке.
Выданные хранятся в `files/os/root/regedit/PERMISSIONS`.

## SuperUser — выдача полного доступа

Команда `su` больше не включает режим суперпользователя: она отвечает
ошибкой и отправляет в приложение. `sudo` работает только когда режим уже
включён. Так сделано потому, что право `superuser` открывает пакету файлы,
реестр, сеть и другие пакеты — такое не выдают одной строкой в терминале.

```text
apt install superuserapp
superuser                     окно выдачи прав
```

Слева список пакетов: имя, тип, есть ли уже право, сколько прав выдано
всего. Выберите пакет — справа появится, что именно откроет право и какие
права у пакета есть сейчас. Отметьте флажок «Я понимаю, что пакет получит
полный доступ» — только после этого станет доступна кнопка
**«Выдать superuser»**. Система ещё раз переспросит в отдельном окне.

Рядом: **«Отозвать»** снимает право, **«Включить режим»** поднимает права
текущего сеанса от имени выбранного пакета, **«Выключить»** опускает их
обратно. Команда `su` без аргументов по-прежнему выключает режим.

## Вход с телефона или другого ПК

Сервер входа — `SshHost`. Это **не** SSH-2: обмена ключами здесь нет,
поэтому обычный клиент `ssh` подключиться не сможет. Работают:

* **PuTTY** — тип соединения **Raw** или **Telnet**, адрес и порт из команды `ssh`;
* `nc <адрес> 2222` — на Linux, macOS и в Termux на Android.

Сначала заведите пользователя — без него сервер не стартует:

```text
user create lilia 1234        создать (пароль хранится как PBKDF2-хэш)
user edit lilia 4321          сменить пароль
user disable lilia            временно закрыть вход
user remove lilia             удалить
user list                     кто заведён и сколько было входов
```

Затем сервер:

```text
ssh                           адреса этой машины и порт
ssh start 2222                запустить
ssh status                    состояние и число подключений
ssh who                       кто сейчас в сети
ssh help                      чем сеанс по сети отличается от терминала
ssh log                       кто и когда подключался
ssh stop                      остановить
```

Команда `ssh` без аргументов печатает адрес целиком — его и вводят на
телефоне. После подключения клиент спросит имя и пароль, дальше это
обычная оболочка LisunOS: те же команды, тот же вывод.

### Что умеет сеанс по сети

Команды выполняет то же ядро, что и терминал, поэтому доступны **все**
команды, включая те, что добавили установленные приложения: `explorer`,
`logs`, `superuser`, `store`, `httpd` и любые свои. Отличий ровно три.

**Окна открываются в LisunOS, а не в ssh.** Форму нельзя показать в
текстовом канале, поэтому окно появляется на самом компьютере, а в ssh
приходит строка о том, что оно открыто. Так ведут себя `explorer`,
`wifi form`, `superuser` и команды приложений.

**Своя текущая папка.** `cd` в одном сеансе не уводит ни терминал, ни
других подключённых: у каждого своя. Приглашение показывает, где вы
находитесь, — `LisunOS:\root\www>`.

**Видна только файловая система LisunOS.** Пути диска Windows
(`C:\...`, сетевые шары) закрыты: `apt install C:\app.lnsh` и указание
своего `php-cgi.exe` по сети откажут. Ставить можно по имени из каталога
и по ссылке.

Ещё в сеансе работают:

```text
clear            очистить экран
!!               повторить прошлую команду
?                короткая справка о сеансе
exit             выйти
```

Одновременно сервер держит до восьми подключений.

Окном то же самое делает приложение **«Доступ по сети»**:

```text
apt install sshapp
ssh-app
```

Адрес с портом и кнопка «Копировать», список пользователей с созданием и
сменой пароля, журнал подключений в реальном времени.

> Порт 2222 должен быть открыт: `ufw port 2222 enable`. Доступ по сети даёт
> вход в оболочку по паролю — не включайте его в чужой сети.

## Журнал ядра

```text
apt install logsapp
logs
```

Окно показывает записи ядра. Поиск отбирает по тексту, список «Источник»
собирается из самих записей (`[store]`, `[ssh]`, `[apt]`, `[FormEngine]`),
флажок «Только ошибки» оставляет строки с `ОШИБКА` и `ERROR`, «Следить»
подтягивает новые записи сам. Кнопка «Сохранить в файл» кладёт то, что
видно на экране, в `/os/home/logs`.

## Если что-то пошло не так

| Симптом | Что делать |
|----------|------------|
| `503 — PHP не найден` | `php-frm status`; при необходимости `php-frm use builtin` |
| PHP не качается | `php-frm mirrors`, проверьте `wifi status`, затем `php-frm download` |
| Порт 8989 не открывается | `perm grant LisunOS.lshall hall`, затем `system start` |
| Сеть не подключается | `wifi status` — если «нужен вход», выполните `wifi portal` |
| Пакет не ставится | `apt info <имя>`; проверьте, что ссылка ведёт на `.lnsh` |
| Права мешают | `perm app <имя>` и `perm grant <имя> <право>` |
| `su` пишет ошибку | так и задумано: откройте `superuser` и выдайте право пакету |
| `ssh start` не запускается | сначала `user create <имя> <пароль>`, затем `ufw port 2222 enable` |
| Клиент `ssh` не подключается | это не SSH-2: PuTTY с типом **Raw** или **Telnet**, либо `nc` |
| По сети не ставится пакет с диска | это запрещено: ставьте по имени (`apt install sshapp`) или по ссылке |
| Команда по ssh «ничего не сделала» | она открыла окно — посмотрите на экран компьютера |

Журнал системы — на вкладке «Терминал», команда `clear` очищает экран.
