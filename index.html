LisunOS — виртуальная ОС на C# WinForms: терминал с пакетным менеджером, собственный движок PHP, HTTP-сервер, Wi-Fi и система разрешений. Один файл, без установщика. LisunOS is a virtual OS built on C# WinForms: a terminal with a package manager, its own PHP engine, an HTTP server, Wi-Fi and a permission system. One file, no installer.

Что внутриWhat is inside

Подсистемы ядра, доступные сразу после запуска.Kernel subsystems available right after launch.

ТерминалTerminal

Автодополнение, история, псевдонимы, русская и английская раскладка.Autocomplete, history, aliases, Russian and English layouts.

Пакеты aptapt packages

Установка из сети, локализованные манифесты, шифрование пакета после установки.Install from the network, localized manifests, package encryption after install.

Свой PHPOwn PHP

341 функция, лексер и интерпретатор написаны с нуля. Сборка PHP докачивается сама.341 functions, lexer and interpreter written from scratch. A PHP build downloads itself.

Веб-серверWeb server

Настройка в стиле nginx, api.php, веб-панель с паролем, прокси на Node.js.nginx-style configuration, api.php, a password-protected panel, a proxy to Node.js.

Wi-Fi

Отдельное приложение: все сети вокруг списком — сигнал, защита, сохранённые. Подключение по двойному щелчку, страница входа открывается сама.An application of its own: every network around in one list — signal, security, saved ones. Connect with a double click, the sign-in page opens by itself.

Кабель и Wi-FiCable and Wi-Fi

Проводное соединение видно наравне с беспроводным: команда net показывает адаптеры, адреса и шлюзы, а VPN и виртуальные коммутаторы за кабель не выдаются.A wired connection counts as much as a wireless one: the net command lists adapters, addresses and gateways, and VPN or virtual switches do not pass as a cable.

Мастер первого запускаFirst-run wizard

При первом запуске вместо терминала — этапы, как при настройке телефона: язык, сеть, выбор приложений с сайта, установка.On the first start, steps instead of the terminal, the way a phone asks: language, network, applications from the site, install.

Пакет под паролемLocked package

Свой пакет закрывается паролем: AES-256-CBC, ключ из PBKDF2, отпечаток HMAC. Без пароля его не прочитать и не поставить.Your own package can be locked: AES-256-CBC, a PBKDF2 key, an HMAC tag. Without the password it cannot be read or installed.

ЗагрузкиDownloads

Одно место на всю систему: прогресс и скорость, зеркала, докачка оборванного файла с того же байта, проверка sha256 и история.One place for the whole system: progress and speed, mirrors, a broken file resumes at the same byte, sha256 checks and history.

КомпонентыComponents

Команда lib показывает, что система может докачать, а что уже внутри неё. Нужное берётся само, когда понадобится.The lib command shows what the system can fetch and what is already inside it. What is needed arrives by itself.

ОбновлениеUpdate

update check смотрит на сайт, update install скачивает новый exe и подменяет текущий. Прежний файл остаётся рядом.update check looks at the site, update install downloads the new exe and replaces the current one. The old file stays next to it.

РазрешенияPermissions

Девятнадцать прав, приложение запрашивает их само, отказ спрашивается повторно.Nineteen rights, an application requests them itself, a denial is asked again.

ПодтверждениеConfirmation

Закрытое ограничением действие подтверждается паролем в окне, как в Windows. Пароль задаётся при первом запуске.An action closed by a limit is confirmed with a password in a window, like in Windows. The password is set on the first run.

SuperUser

Команда su больше не повышает права: пакет выбирают в приложении SuperUser и выдают право вручную.The su command no longer elevates: you pick the package in the SuperUser application and grant the right by hand.

Вход по сетиNetwork sign-in

Обычный клиент ssh с телефона или ПК: обмен ключами и шифрование настоящие. Команды все, включая добавленные приложениями.A regular ssh client from a phone or a PC: real key exchange and encryption. Every command works, including ones applications added.
