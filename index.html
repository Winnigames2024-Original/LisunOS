LisunOS — виртуальная ОС на C# WinForms: терминал с пакетным менеджером, собственный движок PHP, HTTP-сервер, Wi-Fi и система разрешений. Один файл, без установщика. LisunOS is a virtual OS built on C# WinForms: a terminal with a package manager, its own PHP engine, an HTTP server, Wi-Fi and a permission system. One file, no installer.

Что внутриWhat is inside

Подсистемы ядра, доступные сразу после запуска.Kernel subsystems available right after launch.

ТерминалTerminal

Автодополнение, история, псевдонимы, русская и английская раскладка.Autocomplete, history, aliases, Russian and English layouts.

Пакеты aptapt packages

Установка из сети, локализованные манифесты, шифрование пакета после установки.Install from the network, localized manifests, package encryption after install.

Свой PHPOwn PHP

341 функция, лексер и интерпретатор написаны с нуля. Сборка PHP докачивается сама.341 functions, lexer and interpreter written from scratch. A PHP build downloads itself.

Веб-серверWeb server

Настройка в стиле nginx, api.php, веб-панель с паролем, прокси на Node.js.nginx-style configuration, api.php, a password-protected panel, a proxy to Node.js.

Wi-Fi

Поиск сетей, подключение с паролем и без, страница входа открывается сама.Scan networks, connect with or without a password, the sign-in page opens by itself.

РазрешенияPermissions

Девятнадцать прав, приложение запрашивает их само, отказ спрашивается повторно.Nineteen rights, an application requests them itself, a denial is asked again.

SuperUser

Команда su больше не повышает права: пакет выбирают в приложении SuperUser и выдают право вручную.The su command no longer elevates: you pick the package in the SuperUser application and grant the right by hand.

Вход по сетиNetwork sign-in

Команда ssh показывает адрес машины — с телефона или другого ПК в оболочку заходят по логину и паролю.The ssh command prints the machine address — sign in to the shell from a phone or another PC with a login and a password.
